# Мои победы

Трекер личных побед: записываешь достижение — загорается звезда своего цвета.

- Семь направлений: здоровье, деньги, работа, семья, обучение, развитие, другое
- Суперпобеда — главное событие дня, отдельной золотой звездой
- Виды: день, три дня, неделя
- Календарь с количеством побед по дням
- Ставится на домашний экран телефона как приложение

Данные хранятся в браузере устройства и никуда не отправляются.
